MicroCRM Recibos e Orcamentos

Como abrir:
1. Abra o arquivo index.html no navegador.
2. Cadastre os dados da empresa.
3. Cadastre clientes.
4. Gere orcamentos ou recibos e use "Imprimir/PDF" para imprimir pelo navegador.
5. Use "Baixar PDF e compartilhar" para gerar um PDF normal, baixar o arquivo e abrir a tela de compartilhamento do dispositivo quando o navegador permitir.
6. Use a aba Financeiro para ver receita paga, valores a receber, ticket medio, ranking de clientes, status dos documentos e graficos animados por periodo.

Seguranca:
- O aplicativo roda localmente no navegador, sem servidor e sem envio automatico para a internet.
- Os dados ficam no localStorage do navegador usado.
- A exportacao de recibos e orcamentos gera PDF normal pelo motor interno do app, com layout profissional, resumo financeiro, status e area de assinatura.
- Nao existe "seguranca total" contra hackers em nenhum software, mas este formato reduz riscos por nao expor login, banco de dados remoto ou API publica.
- O compartilhamento usa a funcao nativa do navegador/dispositivo. Em alguns computadores ela pode nao listar WhatsApp/Facebook se esses apps nao estiverem instalados ou integrados ao sistema.

Observacao:
Se limpar os dados do navegador, os registros locais podem ser apagados. Exporte os recibos e orcamentos importantes em PDF.
