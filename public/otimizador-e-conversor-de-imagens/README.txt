Otimizador e Conversor de Imagens PRO - Silva Digital Tech

Instruções de Implementação:
1. Mova a pasta 'otimizador-e-conversor-de-imagens' inteira para dentro do diretório 'public' do seu site Astro/Netlify.
2. Link para acessar a ferramenta: /otimizador-e-conversor-de-imagens/index.html
3. Nenhum backend necessário. Esta ferramenta usa a Canvas API e Web APIs para otimizar arquivos 100% Client-Side.
4. Inclui suporte avançado para criação de Favicons (.ico).
5. JSZip integrado via CDN para download em lote de até centenas de imagens.
